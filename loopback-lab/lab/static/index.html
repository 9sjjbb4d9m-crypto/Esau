A fingerprint, not a lock.

A cryptographic hash maps bytes to a fixed-size digest. The same input and algorithm always produce the same digest.

The avalanche effect

A tiny input change usually flips about half the output bits. It need not be exactly 50%.

Mind the bytes

Case, spaces, and newlines all matter. This lab hashes UTF-8 bytes with no normalization.

Plain SHA hashes are not suitable for storing passwords. Password storage needs a dedicated, salted password KDF.

Inside the lab boundary

Local by construction. The launcher binds to 127.0.0.1. The server checks the connection, hostname, and browser origin. Explicit Codespaces mode also allows that Codespace’s preview address; keep its forwarded port Private. All assets are bundled; there are no analytics, CDNs, DNS lookups, scanners, or external API calls.

Ephemeral by default. Inputs and keys are processed in memory. The app uses no database, cookies, or browser storage. Exporting a traffic CSV creates a file only when you choose it. This is not a hardened multi-user service or a memory-erasure tool.
